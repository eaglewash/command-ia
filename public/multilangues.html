Comment fonctionne le multi-langues ?

1
Activez des langues
Cliquez sur une langue ci-dessous pour l'activer. Le Français est toujours actif (langue source). Les langues actives apparaissent sur votre menu QR code client.
2
Traduisez votre menu
Utilisez l'éditeur de traductions en bas de page pour saisir le nom et la description de chaque plat dans chaque langue activée.
3
Le client choisit sa langue
Sur la page QR de votre restaurant, vos clients voient automatiquement un sélecteur de langue. Le menu s'affiche dans la langue choisie.

Langues disponibles

Paramètres d'affichage

Sélecteur de langue visible
Affiche les drapeaux sur la page QR client pour que le client choisisse sa langue
Détection automatique de langue
Détecte la langue du navigateur du client et affiche le menu dans cette langue automatiquement
Fallback sur le français si traduction manquante
Si un plat n'est pas encore traduit, affiche le nom français au lieu d'un champ vide
Traductions dans les reçus
Le reçu imprimé est généré dans la langue du client
