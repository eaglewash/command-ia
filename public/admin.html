Clés API
Gestion des accès API par restaurant — visible uniquement pour l'Admin
Comment fonctionnent les clés API ?
Chaque restaurant peut disposer d'une clé API unique pour intégrer Commande-IA avec des outils tiers (caisses, logiciels de compta, POS…). Les clés sont transmises dans l'en-tête Authorization: Bearer <clé>.
Ne jamais partager une clé en clair. En cas de compromission, révoquez-la immédiatement.
